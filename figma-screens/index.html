How to Import into Figma in 1-Click

Convert these HTML files into editable vector frames in Figma.

Method A: html.to.design Plugin

In Figma, run the plugin html.to.design. Choose "Import from raw HTML / Local file", and select the .html file. It generates auto-layout vector frames instantly.

Method B: Local Live Server URL

Run a quick local server (or open with VS Code Live Server), then paste the URL (e.g. http://localhost:5500/figma-screens/1-home.html) directly into html.to.design.

Method C: Builder.io Plugin

Open the Figma plugin Visual Copilot / HTML to Figma by Builder.io, paste the HTML code snippet directly into the plugin window, and click "Import to Canvas".
